Dart Grade Computation

Name: Atibagos, Angela G.
Section: BSIT 3.1

Scenario:
This Dart program demonstrates a simple grade computation scenario by calculating a student's total and average grades and determining whether the student passed.

Data Types Used
-String — student name
-int — number of subjects
-double — quiz, assignment, exam, total, and average grades
-bool — student status and passing result
-Operators Used

The program demonstrates:
+ for adding grades
- for calculating remaining subjects
/ for calculating the average
~/ for integer division
% for finding the remainder
>= for checking whether the average grade is passing

How to Run

Open the project folder in a terminal and run:
dart run

To format the program:
dart format .
